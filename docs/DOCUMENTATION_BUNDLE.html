⚡ 1. Setup & Installation Guide

Prerequisites

  • Java JDK 21 or higher
  • Node.js 18 or higher

Backend Setup (Spring Boot)

.\mvnw.cmd spring-boot:run
  • REST API: http://localhost:8080/api
  • H2 Database Console: http://localhost:8080/h2-console (JDBC: jdbc:h2:mem:investmentdb, User: sa, Password: blank)

Frontend Setup (React + Vite)

cd frontend
npm install
npm run dev
  • UI URL: http://localhost:5173

📑 2. REST API Documentation

HTTP Method Endpoint Path Description
GET /api/portfolios/{investorId} Returns investor details, portfolios, product holdings, and 90% withdrawal caps.
POST /api/withdrawals Executes business rule validation, balance deduction, and creates notice.
GET /api/withdrawals Retrieves past withdrawal notices with optional query date range filters.
GET /api/withdrawals/export/csv Exports filtered withdrawal statements as a downloadable CSV file.

Business Rule Validation Engine

Rule Validation Description Error Code
Retirement Age Restriction Retirement product withdrawals require investor age > 65 RETIREMENT_AGE_RESTRICTION
Balance Sufficiency Requested withdrawal amount must not exceed balance INSUFFICIENT_BALANCE
90% Withdrawal Cap Requested withdrawal amount must not exceed 90% of balance CAP_90_PERCENT_EXCEEDED
